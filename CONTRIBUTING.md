# Contributing

Contributions are welcome. Read [CONTRACT.md](CONTRACT.md) before proposing a behavior change; it defines the 0.1.0 contract. Discuss changes in an issue and keep contributions focused. Do not include sensitive data in examples, issues, or tests.

Use Node.js 20 or later. Install dependencies with `npm ci` and run `node scripts/test.js`. Validate the examples with the commands in [examples/README.md](examples/README.md). Include tests appropriate to a change, especially for input safety and MCP interoperability. CI runs on Linux, Windows, and macOS with Node 20, 22, and 24.

Contributions are licensed under [Apache-2.0](LICENSE). Report security issues privately using [SECURITY.md](SECURITY.md).
